# discounts-api

Backend: карта студенческих скидок.

## Что нужно установить

- [Go](https://go.dev/dl/) 1.27 или новее

## Запуск

Из корня репозитория:

```
go run ./cmd/api
```

Сервер запустится на `127.0.0.1:8080`. Чтобы проверить его, откройте http://127.0.0.1:8080/health. В ответ придёт:

```json
{"status":"ok"}
```

Остановить сервер: `Ctrl+C`.

## Тесты

```
go test ./...
```

## Настройки

Настройки задаются переменными окружения.

| Переменная | Назначение | По умолчанию |
|---|---|---|
| `HTTP_ADDR` | адрес и порт сервера | `127.0.0.1:8080` |

Список переменных есть в `.env.example`. Файл `.env` сервер сам не читает.

Пример запуска на другом порту в PowerShell:

```powershell
$env:HTTP_ADDR = "127.0.0.1:9090"
go run ./cmd/api
```

## Логи

Сервер пишет логи в терминал. Для каждого запроса записываются метод, путь, код ответа и время обработки. Параметры запроса после `?`, заголовки и тело запроса в эту запись не попадают.

Если при обработке запроса происходит `panic`, подробности записываются в лог, клиент получает код `500` без подробностей, а сервер продолжает работать.

## Структура проекта

| Путь | Что внутри |
|---|---|
| `cmd/api` | точка входа, запуск и остановка сервера |
| `internal/config` | чтение настроек |
| `internal/httpapi` | маршруты и middleware |
| `DOCS` | архитектура и черновик API |
