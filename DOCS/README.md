# Документация бэкенда

Карта студенческих скидок с пользовательским контентом. Документы находятся в работе и обновляются по ходу проекта.

## Содержание

- [openapi.yaml](openapi.yaml): контракт API в формате OpenAPI (Swagger). Черновик, будет уточняться вместе с фронтендом.
- [architecture.md](architecture.md): архитектура системы: контекст, контейнеры, компоненты бэкенда и сквозной сценарий.

## Планируется

- Схема базы данных
- Модель угроз и описание защиты API
